# Ecotum Health Guide

இப்போ project என்னன்னா Ecotum AI. Ecotum AI அப்படின்னா, இப்ப நான் வந்து என் கைய வந்து photo எடுத்து அனுப்பிச்சின்னா அதுல இது என்ன disease, இப்போ இது-இதோட risk level medium-ஆ இருக்கா இல்ல இது low-ஆ இருக்கா, starting state-ஓ இல்ல இது risk state-ல இருக்கு, second stage-ல இருக்கா அந்த மாதிரி சொல்ற மாதிரி இருக்கணும். plus அதோட risk percentage-ம் சொல்லணும். அதே மாதிரி base பண்ணி இந்த ஒரு சில environmental science-க்கு ஏத்த மாதிரி ஒரு சில factors எல்லாம் இருக்கும்ல்ல. இந்த UV index, AQI, Air Quality Index அந்த மாதிரி factors, இப்ப temperature, இப்போ என்ன speed-ல காற்று போயிட்டு இருக்கு, sorry wind ஓட speed. இந்த மாதிரி வச்சு அதோட risk level, இதனாலதான் இது வந்துச்சு, இதனாலதான் இப்படி ஆச்சு அந்த மாதிரி ஒரு prediction குடுக்கிற மாதிரியும் plus இது என்ன பண்ணும்னா, இ-இப்போ இதுக்கு இதுக்கு ஏத்த மாதிரி nearest dermatologist-ஐ recommend பண்ணும். First இப்படி suggest பண்ணணும். ஒரு report-ஐ generate பண்ணாலும் okay தான். இப்போ இந்த report generate பண்ணிட்டு இப்ப பக்கத்துல இருக்க dermatologist-ஐ நம்ம வந்து suggest பண்ணிக்கிற மாதிரி. இப்போ history-ஐ நம்ம பாத்துக்கலாம். இல்ல report-ஐ எடுத்துக்கலாம். இல்ல வந்துட்டு delete பண்ணணும்னு delete பண்ணிக்கலாம். என்ன வேணா பண்ணிக்கலாம். இது நம்மளோட விருப்பம். இதை வந்து ஆப் ஆப் பண்ணுவோம். முடியுமா?
